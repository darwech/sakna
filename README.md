# سكنة — النسخة النهائية الحالية

## شكل بيانات السكن
لم يعد هناك حقل "اسم الشقة" في لوحة الأدمن.
بدلًا منه يتم تسجيل:
- المحافظة
- المنطقة
- الجامعة
- عدد الغرف
- عدد السراير
- عدد السراير المتاحة
- السعر للسرير شهريًا
- المميزات
- الوصف
- الصور
- الفيديو
- حالة السكن

اسم داخلي يتم توليده تلقائيًا في قاعدة البيانات للتوافق فقط، وليس ظاهرًا للأدمن أو الطالب.

## تحديث Supabase
شغّل الملف:
`supabase-location.sql`

## التحسينات الأخيرة
- favicon + Open Graph / Twitter card.
- زر واتساب عائم في الصفحات العامة.
- Skeleton loading للكروت.
- حالة السكن ديناميكية: متاحة / آخر سرير / مكتملة.
- Placeholder داخلي بدل صورة Unsplash عند غياب الصور.
- مفضلة محلية LocalStorage.
- معرض صور احترافي: صورة رئيسية + صور مصغرة + فيديو.
- رابط خرائط جوجل مبني من المنطقة/المحافظة أو location_text.
- فلاتر الصفحة الرئيسية ديناميكية من قاعدة البيانات.
- لوحة الأدمن فيها بحث وفلترة.
- زر حفظ الأدمن يتحول إلى "جاري الحفظ..." ويُمنع الضغط المكرر أثناء الرفع.


## عرض اسم السكن
المنطقة هي العنوان الرئيسي الظاهر للطالب (مثل: الكوامل / الكوثر)، والجامعة تظهر كسطر ثانوي. المحافظة لا تظهر كعنوان كبير.
